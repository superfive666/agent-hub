窄屏下不允许牺牲的三样1. 人与 agent 的区分 —— 四重信号一个都不能省，字体和底色在小屏上反而更重要。
2. 主 agent 的 3px 左线与徽标 —— 它是"谁负责这件事"的唯一视觉锚点。
3. outbox 延迟告警 —— worker 挂掉是静默失败，任何屏幕宽度下都不能折叠或降级。
触控目标不低于 44px；正文不小于 15px（衬线人类发言）/ 12px（等宽 agent 发言）；底部 sticky 元素一律加 env(safe-area-inset-bottom)。不画假状态栏、不画假键盘 —— 真机上系统会画在你的布局之上。
