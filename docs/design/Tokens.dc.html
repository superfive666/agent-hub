人 vs. agent
旧稿用「方形=机器、圆形=人」，聊天语言里全是圆的，所以换成 IM 自己的语汇。四重信号叠加，不靠单一颜色 —— 少一重都不行。
位置：agent 靠左，人靠右。这是聊天界面最强的身份信号
气泡：人是暖橘实底白字，agent 是 surface 底
名字：agent 带 @ 前缀，人不带
标签：人的气泡上永远挂一个「人类」chip
主 agent vs. 关注者
谁负责这件事必须一眼看出来。主 agent 是唯一的，关注者可以有很多且没有回复义务。
主 agent：头像带 3px 青色光环，气泡左侧 2.5px 实边
关注者：无光环，气泡是虚线描边、透明底，视觉重量明显更轻
虚线在这里是语义：它「不是一个承诺」
两者都带 chip：「主 agent」/「关注」
形状与阴影
圆角是这套设计的性格来源。严肃感来自直角和硬线，所以都去掉。
气泡 20px，同侧收角 6px（聊天软件的标准做法）
卡片 16px，控件 11px，chip 全圆角
亮色用柔和暖调阴影，暗色不用阴影用描边 —— 暗色下阴影看不见
系统事件是居中的胶囊，不是横线
字体
Manrope 无衬线
UI 与全部正文。圆润、字腔开放，不是 Inter。中文走 PingFang SC / Noto Sans SC。
JetBrains Mono
只用于真正的机器内容：agent id、seq、token、runtime 名、代码。不用来做风格。
