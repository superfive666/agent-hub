毛玻璃面
背景模糊 26px + 饱和度 150%，1px 描边，内侧 1px 高光。暗色下用描边代替阴影 —— 阴影在深底上看不见。
流光边框 · glow
conic 渐变绕角度旋转，mask 掏空中间只留 1.2px 边。7 秒一圈，慢到不吵。
边缘流光 · runner
一道亮带 3.4 秒跑一圈。给“正在进行”的东西用，比常亮更有紧迫感。

3D 球体
三层叠加：高光 radial + 色偏 radial + conic 虹彩；内阴影做出球面终止线，外发光做氛围。两条轨道环用 rotateX(74deg) + preserve-3d，反向不同速旋转 —— 纯 CSS，没有 WebGL，因为画板 iframe 是无网络出口的。
动效清单
breathe 4.5s主 agent 头像、品牌标、球体缓慢的 1 → 1.045 缩放。它在说“这个 agent 活着”
pulse 2.6s在线状态点明暗呼吸，比一个静止绿点更能表达“连接是活的”
rise .62s消息、卡片、会话项入场从下方 16px 浮起，按 nth-child 错峰 70ms
spin 7s流光边框conic 渐变绕角度旋转；runner 变体是一道亮带 3.4s 跑一圈
drift 26s背景着色器渐变四团模糊色球缓慢漂移缩放，整页有呼吸
dust 34s粒子场90 颗粒子整体缓慢平移，制造纵深
hover .28s按钮 / 卡片 / 气泡 / 头像抬升 1.5–2px、描边提亮、主按钮辉光加强

/* 流光边框 —— 只挂在有语义的元素上 */
@property --ang { syntax:'<angle>'; initial-value:0deg; inherits:false; }
.glow::before{
  content:''; position:absolute; inset:0; border-radius:inherit; padding:1.2px;
  background:conic-gradient(from var(--ang),
    var(--i1),var(--i2),var(--i3),var(--i4),var(--agent),var(--i1));
  -webkit-mask:linear-gradient(#000 0 0) content-box,linear-gradient(#000 0 0);
  mask-composite:exclude; animation:spin 7s linear infinite;
}
@keyframes spin{ to{ --ang:360deg } }

/* 毛玻璃 */
.glass{
  background:var(--surface);
  backdrop-filter:blur(26px) saturate(150%);
  border:1px solid var(--line);
  box-shadow:0 1px 0 rgba(255,255,255,.08) inset,
             0 26px 60px -28px rgba(0,0,0,.95);
}

/* 着色器渐变（.app::before）+ 粒子场（.app::after，多重 box-shadow） */
.app::before{ background:
    radial-gradient(38% 32% at 14% 12%, var(--amb1), transparent 70%),
    radial-gradient(34% 30% at 84% 20%, var(--amb2), transparent 70%), ... ;
  filter:blur(58px); mix-blend-mode:screen;
  animation:drift 26s var(--ease) infinite alternate; }

/* 减弱动效必须尊重 */
@media (prefers-reduced-motion: reduce){
  *,*::before,*::after{ animation:none!important; transition:none!important }
}
