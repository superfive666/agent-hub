设计系统 · 液态玻璃
底盘不是"侧栏 + 头部 + 右栏"那套 dashboard chrome，而是舞台 → 玻璃板 → 嵌套内板三层构图。面板悬浮在有天气的背景之上，板中有板，边缘有厚度。
亮色是液态玻璃（棱镜色散、焦散光带），暗色是霓虹光影（角度渐变描边、彩色氛围光）——同一套技术，两种气候。
特效只给有语义的地方
流光只挂在主 agent 与当前会话上。这张卡自己挂着它，因为它在示范这条规则。

厚度是怎么来的 —— 六层阴影
半透明 + 一条 1px 描边只能做出"一张纸"。厚玻璃需要把光在玻璃里的行为拆开画。
inset 0 1.5px 0 #fff顶边高光玻璃的上沿被光打亮 —— 厚度感的第一来源
inset 0 -1px 0 rgba(255,255,255,.55)底边回光下沿的一丝反射，让板子不像纸片
inset 0 22px 44px -28px #fff内顶泛光光从上方漫进玻璃内部
inset 0 -30px 52px -34px rgba(60,115,150,.42)内底暗部玻璃自身的厚度投在内部的阴影
0 36px 74px -36px rgba(20,55,85,.42)投影板子浮在舞台上方，不是贴着
0 2px 10px -5px rgba(20,55,85,.18)接触阴影紧贴边缘的一层，钉住位置
板中有板
外板厚、内板淡。内板靠内阴影"嵌"进去，不是叠上去 —— 这是液态玻璃的核心手感。
棱镜色散边
conic 渐变绕角度旋转 16 秒一圈，mask 掏空只留 1.4px。亮色 .42 透明度是色散，暗色 .85 就是霓虹描边。
胶囊化控件
按钮、输入框、chip、分段器全是全圆角。主按钮薄荷渐变 + 右侧箭头，这是参考图里最强的形状记号。

动效清单
weather 30s舞台背景焦散光带与色散缓慢移动旋转，整页有天气
sheen 14s玻璃板一道高光横扫板面 —— 液态感的来源
spin 16s / 7s棱镜边 / 语义流光板边 16 秒一圈很慢，语义流光 7 秒，跑马灯 3.6 秒
breathe 5s主 agent、品牌标、球体1 → 1.05 缩放。页面上唯一会喘气的东西
pulse 2.8s在线状态点明暗呼吸，比静止绿点更像"连接是活的"
rise .66s消息、卡片、会话项入场从下方 18px 浮起，nth-child 错峰 70ms
dust 40s尘埃粒子（暗色）80 颗粒子缓慢平移，制造纵深
hover .3s所有可点元素抬升 2px；主按钮辉光扩散；会话项右移 3px
全部走同一条缓动 cubic-bezier(.22,.61,.28,1)；prefers-reduced-motion 下全量关闭。

/* 舞台 —— 不是"页面底色"，是一张有天气的背景 */
.app{
  padding:22px; gap:16px; display:flex;
  background:
    radial-gradient(78% 58% at 16% 4%,  #c9e9f7 0%, transparent 58%),
    radial-gradient(64% 52% at 86% 10%, #dcdcff 0%, transparent 60%),
    radial-gradient(86% 62% at 62% 104%,#dffaf0 0%, transparent 58%),
    linear-gradient(168deg,#cfe4f0 0%,#e2eff5 42%,#eef8f8 100%);
}
/* 焦散光带 + 棱镜色散，30s 缓慢移动 */
.app::before{
  background:
    conic-gradient(from 210deg at 30% 20%,transparent 0 18%,rgba(255,255,255,.5) 24%,transparent 30%),
    linear-gradient(104deg,transparent 40%,rgba(255,120,220,.28) 46%,
      rgba(120,220,255,.30) 50%,rgba(180,255,200,.26) 54%,transparent 60%);
  filter:blur(46px); animation:weather 30s var(--ease) infinite alternate;
}

/* 厚玻璃板 —— 六层 box-shadow 叠出厚度 */
.rail,.main{
  border-radius:30px;
  background:linear-gradient(158deg,rgba(255,255,255,.66),
             rgba(255,255,255,.34) 46%,rgba(255,255,255,.52));
  backdrop-filter:blur(30px) saturate(190%) brightness(1.04);
  border:1px solid rgba(255,255,255,.75);
  box-shadow:
    inset 0 1.5px 0 rgba(255,255,255,1),
    inset 0 -1px 0 rgba(255,255,255,.55),
    inset 0 22px 44px -28px rgba(255,255,255,1),
    inset 0 -30px 52px -34px rgba(60,115,150,.42),
    0 36px 74px -36px rgba(20,55,85,.42),
    0 2px 10px -5px rgba(20,55,85,.18);
}
/* 棱镜色散边：亮色 opacity .42，暗色 .85 就成了霓虹角度渐变描边 */
.rail::before,.main::before{
  padding:1.4px; border-radius:inherit;
  background:conic-gradient(from var(--ang),var(--i1),var(--i2),var(--i3),var(--i4),var(--i5),var(--i1));
  -webkit-mask:linear-gradient(#000 0 0) content-box,linear-gradient(#000 0 0);
  mask-composite:exclude; opacity:var(--prism-op); animation:spin 16s linear infinite;
}
/* 高光扫过：液态感的来源 */
.rail::after,.main::after{
  background:linear-gradient(126deg,transparent 30%,rgba(255,255,255,.85) 46%,transparent 58%);
  mix-blend-mode:overlay; animation:sheen 14s var(--ease) infinite;
}
